# 智慧安农 VPN：OpenWrt 研究版 0.5.1

本包为 Linux / OpenWrt 非官方兼容性研究客户端；面向熟悉 OpenWrt 网络配置的用户。校园账号、密码和个人路由器配置不包含在包中。仅支持经学校授权的资源，服务端接口和学校配置可能变化。请自行确认校园规定和软件分发许可。

## 包含内容

- `releases/*.ipk`：aarch64_cortex-a53 架构的 OpenWrt 安装包（需 opkg）；其他架构请自行构建并调整架构声明。
- `native/`、`openwrt/`：源码、LuCI 界面和服务配置；ZIP 压缩包中的 `dist/` 包含 ARM64 和 x86-64 Linux 可执行文件。
- `build.sh`、`package-openwrt.py`：构建脚本。

## 安装和使用前

安装前备份路由器配置，确认 CPU 架构、系统软件包及网络拓扑。安装包默认禁用服务，默认 `network_profile=none`、未设置设备 ID、目标范围和凭据文件；安装后不能直接作为全网即用 VPN，也不会自动设置 DNS。需根据设备设置随机稳定的设备 ID、校园服务端授予的目标范围、实际 LAN 网段，以及是否启用实验性 dorm-router 网络适配；切勿照搬其他路由器的专用配置。应用仅对校方授权资源内的目标做策略路由。四拨、透明代理、防火墙和 DNS 组合需逐项验证。仅控制界面显示已连接并不代表目标网站已可用。

1. 将安装包复制到路由器，在终端执行 `opkg install /tmp/campusvpn.ipk`（文件名按实际调整），确保依赖、LuCI 和 rpcd 可用。
2. 查看 `/etc/config/campusvpn`，按实际网络和学校授权情况配置 `device_id`、`network_profile`、`data_profile`、`lan_source`、`resource_target`、`credential_file` 等；设备 ID 应由设备本机安全随机生成并持久保存。凭据路径示例可设为 `/etc/campusvpn/credentials.json`；该文件由登录过程创建，目录和文件权限受限，但内容为明文，路由器 root 用户或备份读取者可见。请勿把凭据复制到公开目录或分享配置备份。
3. 将 `enabled` 设为 1，启用并启动 `/etc/init.d/campusvpn` 服务。通过 HTTPS 登录 LuCI，在“服务 → 智慧安农VPN”填写账号密码并保存连接。仅在受信任的局域网使用管理界面；首次连接若遇证书提示，请自行核验路由器证书。
4. 针对所需校园域名检查 DNS A/AAAA 和真实访问路径；若客户端使用独立代理、加密 DNS 或 IPv6，流量可能绕过 IPv4 分流。不要把示例地址视为长期有效：学校更换地址时须重新核对。

开机自动连接和断线恢复依赖服务启用、有效凭据与可达的控制器；离线时不提交账号登录，在线重试有上限，认证拒绝会暂停等待人工处理。无法保证所有校园认证流程、网络变更或长期运行均无需人工介入。服务端账号政策、验证码及密码修改可能要求重新登录。

## 本地构建

Go 1.23 或更高版本、Linux 环境：`sh build.sh`。构建不下载依赖；执行 `python3 package-openwrt.py` 可生成 ARM64 安装包。项目仅使用 Go 标准库。测试和配置均应在隔离环境进行，再针对实际设备验证。

## 验证范围

开发设备上曾验证校园 VPN 自动登录、一次整机重启后自动连接、目标站点工作台可访问；不同设备未做通用兼容性验证，真实断网恢复及长期稳定性尚未验收。发布包未含个人网络诊断、校方原始客户端或逆向产物。
